Vá HTTPS cho E72 / E6

Bản chữ từ hướng dẫn PDF bạn cung cấp. Cần máy đã có ROMPatcher+ và quyền truy cập thư mục hệ thống theo tài liệu.

Tải MBedTLS-1.4.3.sis
Tải ssl-v21.zip
Tải PDF gốc (10 trang)

1. Chuẩn bị

Giải nén gói trên máy tính. Chép MBedTLS-1.4.3.sis và ssl-v21.zip vào điện thoại. Thoát game.

2. Bật quyền truy cập

Mở ROMPatcher+, bật InstallServer và Open4All.

3. Sao lưu thư viện nếu có

Dùng X-plore kiểm tra C:\sys\bin\ssl.dll. Nếu đã có file này, sao lưu trước. Nếu chưa có thì bỏ qua bước sao lưu.

4. Cài MBedTLS

Cài MBedTLS-1.4.3.sis vào bộ nhớ máy C:. Nếu gặp lỗi cài đặt, dừng lại và kiểm tra thông báo lỗi.

5. Chép thư viện SSL

Dùng X-plore giải nén ssl-v21.zip vào gốc C:\. Kiểm tra file nằm đúng ở C:\sys\bin\ssl.dll, không bị lồng thêm thư mục.

6. Khởi động lại

Khởi động lại điện thoại. Kiểm tra ngày giờ máy. Mở game → Online → Đăng nhập, cấp quyền mạng khi máy hỏi.

7. Chọn điểm truy cập

Kiểm tra cài đặt điểm truy cập mặc định và quyền kết nối của Gunny Java trong Quản lý ứng dụng. Chọn Wi-Fi hoặc điểm truy cập đang dùng. Nếu mất mạng, game trở về sảnh; chọn Online để đăng nhập lại.
