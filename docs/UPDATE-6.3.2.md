# Gunny Java 6.3.2

- Bỏ biểu tượng chân thú và ngựa khỏi thanh công cụ, bao gồm vùng chạm và thứ tự chọn bằng phím. Giữ Shop, Túi, Bạn bè, Hướng dẫn và Thoát.
- Khôi phục nhà Online đúng vị trí, kích thước và phối cảnh trong nền PC gốc `source-assets/lobby/native-hall-background.png`; không ghép nhà rời lên ô đất nữa. Nhãn Online và vùng chạm đi theo công trình gốc.
- Không thay giao thức, luật trận hay SQL. Nếu server đang chạy 6.3.1 thì chỉ cần cài lại game 6.3.2 để dùng hai thay đổi giao diện.
- Gói server cũng cập nhật trang tải `/download/` sang JAD/JAR 6.3.2. Chỉ cần upload gói server nếu muốn trang tải cung cấp bản mới; không cần SQL mới.

Giữ các sửa kết nối và xử lý người rời trận của 6.3.1. Chưa kiểm tra trực tiếp trên Nokia vật lý.
