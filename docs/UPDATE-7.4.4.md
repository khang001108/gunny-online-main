# Shared popup and room controls 7.4.4

NativePopup reuses core frame/button artwork for notices, choices, startup audio prompt, in-battle menu and departure decisions. Online pause is a local menu; simulation continues. Exit requires confirmation and other players receive the server-issued departure choice through the shared popup.

Room headers/loadout/map move upward, solo matching overlay is centered below Free, reminder panels removed from loading artwork. Room softkeys: left invites, right starts/readies/cancels; team slot focus supports OK close/open. Exchange tab has custom input and quick 100/1000/10000-coin conversions at 100:1, with success shown only after the authoritative reply online.

No SQL migration. Not deployed to Render.
